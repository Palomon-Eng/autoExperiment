Panel labels ("Intake" / "Chamber") and MAC addresses are set in config.py. AirSENCE's tiles are built from whatever pollutant fields the unit actually reports (config.AIRSENCE_FIELD_MAP). CSV is a long-format log (timestamp, source, field, value, unit). A fresh file is started every time the app is launched — sensor readings (M5Stick, Aranet4, AirSENCE) are written once a minute per source; Arduino status/stage events are written immediately as they happen. The Arduino itself is control-only here — no sensor readings are read from it.
